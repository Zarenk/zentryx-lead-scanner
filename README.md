# Zentryx Lead Scanner

Script de Tampermonkey que revisa Upwork, Facebook, Workana, Freelancer, Get on Board, LinkedIn, Computrabajo, Bumeran, Torre, HN y bolsas remotas, filtra ofertas y avisa por Telegram.

Instalar/actualizar: abrir el archivo raw de `zentryx-lead-scanner.user.js` con Tampermonkey instalado.

El token de Telegram se guarda en el almacenamiento de Tampermonkey (menú "Configurar Telegram"), nunca en este repositorio.
